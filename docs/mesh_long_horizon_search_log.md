## 2026-08-31 -- Original MATLAB audit and closed-contour refinement

The Python post-processing path was checked against the bundled MATLAB NACA4412
reference using the identical `data/ZSTAT/int_fld` and `data/int_mesh.mat`.
There is no port discrepancy: maximum absolute differences are `1.11e-16` in
`Cl`, `1.39e-17` in `Cd`, `1.39e-17` in `Cd_p`, `1.74e-18` in `Cd_f`, and
`2.84e-14` in `L/D`.  The full profile quantities also retain the existing
float64-level agreement.

The audit instead found a material issue inherited from the MATLAB method:

1. `read_data_profiles.m` defines `pinf=max(P)-0.5`, and
   `load_prof_data.m` integrates pressure relative to that value.
2. `create_profiles_wing*.m` constructs the uniform downstream leg with the
   MATLAB colon expression `x(end):dx:1`.  Unless the spacing lands exactly on
   1, the upper and lower surface integrations end at different points before
   the trailing edge.  A constant-pressure offset then produces a non-zero
   resultant force, even though it should cancel on a closed airfoil contour.
3. The original scripts also drift between `transition_x=0.3` and `0.395`,
   whereas the archived NACA4412 mesh reconstructs to `0.295`.  The active
   `wrt_int_mesh_wing.m` calls the `.395` helper, so it is not a reliable
   reproduction source for the archived NACA4412 force mesh.

For the prior 128-station refined open mesh (`x_last=0.99638`), a unit change
in the pressure reference changes computed `Cd` by `-2.05e-3`.  Explicitly
adding the exact trailing-edge station closes the contour and reduces both the
normal and axial unit-pressure residuals to float64 round-off.  This is a
method correction, not a divergence from the MATLAB implementation.

## 2026-08-31 -- Control-volume momentum balance (backward Cl/Cd)

The original MATLAB tree has the two pieces needed to make a control-volume
check, but not the calculation itself.  `C_create_int_mesh_farfield.m` writes
a Cartesian interpolation grid, while the commented `ControlVolume` branch in
`A1_create_int_mesh_wing.m` specifies the paper's Region-1 rectangle:
`x=-0.25:0.0025:1.25` and `y=-0.25:0.0025:0.25`.  The downstream MATLAB
reader (`C01_naca_wing_farfield.m`) only loads and plots fields; no momentum
flux, Reynolds-stress, or pressure integral is implemented there.

The Python `clcd-backward` workflow now accepts
`clcd_backward.method: control_volume` (the command alias
`backward-clcd` is also accepted).  It reads only the fields required by the
Appendix-2 balance:

- `F1`, `F2`, `F4`: mean `U`, `V`, and pressure;
- `F5`, `F6`, `F9`: total second moments, converted to
  `u'u'`, `v'v'`, and `u'v'` by subtracting the mean products.

The force is integrated with outward normals over the four edges of the
rectangular Cartesian mesh.  A spatially constant pressure is removed before
the edge quadrature; this is exactly neutral on a closed control volume and
avoids a gauge-pressure cancellation error.  For comparison to the existing
surface force coefficients, the reported airfoil load uses the conventional
exterior-control-volume sign,
`-integral(rho*U*(U.n) + rho*u'u'.n + p*n) ds`.  This differs from the
paper's displayed convention in the sign of the first (mean-momentum) term;
the selected convention is verified by closure against the surface method.
The paper's equation has no viscous boundary-flux term, so none is inserted.

`configs/naca4412_control_volume_long_cycle.yml` reproduces the paper bounds
and spacing exactly: 601 x 201 = 120,801 interpolation points.  It was run
with the same files-25--48 accumulator-reset partition as the mesh study,
using `backward-clcd`, and retains all 11 per-block `int_fld` files for audit.
